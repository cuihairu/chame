# ADR-0004: EVM Nonce 首期单实例协调

- 状态：已接受（代决，用户可推翻）
- 日期：2026-10-15
- 对应规格：§7.5、§23 第 4 项

## 背景

§23 要求决定首期是否支持多实例共享账户并发写入（横向扩容的多个 Chame 实例共用同一签名账户）。

## 决策

首期支持**单实例内**的每账户 nonce 协调：每网络每账户一把锁串行分配，本地分配器保证普通并发调用不会重复分配同一 nonce。**不支持**多实例共享账户并发写入，作为明确的使用限制写入文档；多实例方案（数据库租约式 nonce 池）留待后续版本评估。

## 理由

- 规格 §19 Phase 5 验收只要求「EVM 不会因普通并发调用重复分配同一个本地 Nonce」，即单实例语义。
- 多实例 nonce 协调需要持久化租约、实例故障后的租约回收与链上 nonce 对账，超出首期范围；未经完整设计就宣称支持违反 §21.2。

## 备选方案

- **首期即做 DB 租约 nonce 池**：否。依赖持久化与故障恢复配套，复杂度高且验收成本大。

## 影响范围

- 文档必须明确：同一签名账户同一时刻只能由一个 Chame 实例写入；违反此限制的部署不受支持。
- nonce 分配器属于 `adapters/evm` 内部实现，不进入公共契约。

## 测试要求

- 并发取 nonce 不重复、失败回退不跳号的 race 测试（`-race` 下运行）。
- 交易提交结果未知时的 nonce 对账测试在 Phase 5 故障注入中覆盖。
