# 架构决策记录（ADR）

本目录记录 Chame 的架构决策。每个决策一个文件，编号递增，永不复用编号；被替代的决策改为「已替代」并指向新编号，不删除。

来源：规格 §23 列出的实施前决策项。这批 ADR（0001–0008）为**代决**：依据 todo.md 记录的用户授权（"用户已授权代决，逐条给出推荐方案并标注"）由代理决策人于 2026-10-15 作出，每份均标注推荐方案与理由，用户可随时推翻——推翻时新增或修订 ADR 并说明。

## 格式

每份 ADR 包含：状态、日期、背景、决策、理由、备选方案、影响范围、测试要求。
